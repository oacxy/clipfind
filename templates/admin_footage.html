Footage Admin

Downloads background gameplay/relaxation footage into the shared library Story Studio's video generator pulls from. Not linked from the main app — bookmark this page. Every action here calls the same secret-gated backend routes the cron jobs use, so nothing happens without the real server secret below.

Upload a video file (recommended)

Download the YouTube video yourself (any way you like), then upload the finished .mp4 here. No proxy, no bot-detection, nothing to babysit — this just saves the file and adds it to the library.

Or: let the server download it from a URL

This goes through YouTube's bot-detection and a proxy, so it's less reliable than uploading — only use this if uploading isn't an option.

Downloads run in the background now, so this won't time out — but for a quick first test, try 2 instead of 15.
